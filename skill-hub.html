📖 怎么用这个 Hub

1️⃣ 找到合适的 Skill

用顶部搜索框输入业务场景关键词（如 "离职"、"访谈"），或按分类 / 状态筛选。点开卡片看详情。

2️⃣ 复制安装命令

在卡片详情里，点 📋 复制 拿到 use_skill 命令，粘到 Claude Code / Cursor 对话即可加载。

3️⃣ 反馈 / 贡献

用过觉得好用，或者有新场景想加进来，找章老师 Push 一版。Hub 数据全在 data/skills.json。

⚠️ 隐私与合规提醒

所有 HR 敏感数据（员工姓名、薪资、绩效）请在本地脱敏后再喂给 AI；对外分享 Hub 链接前，确认所选 skill 不包含内部敏感信息。
